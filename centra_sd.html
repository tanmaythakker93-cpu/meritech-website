Centra-SD

Manage field tests from a central dashboard

Centra-SD consolidates measurement data into a central repository and shows network performance in a browser interface. Schedule tests on field devices remotely, track their status, and investigate issues on the map as data is uploaded.

Overview

Monitor and manage field tests in one place

Manage supported test devices and uploaded measurements from an authorised browser session. Create groups, assign schedules, track available device status and inspect performance by time and location. Hosting, access controls, integrations and capacity are specified for the deployment.

Main features

Scheduling, consolidation and investigation

Centra-SD brings remote device management, test scheduling, automatic data collection and map-based KPI views into one browser-accessible platform. The tabs below show what it does, what it offers and why it helps.

  • Remotely schedule and monitor test devices
  • Explore KPI data through an interactive map interface
  • Remotely schedules test runs on connected field devices and auto-uploads data to the central repository
  • Works with Sigma-NEO for AI-driven measurement control and analysis
  • Export data for deeper analysis
  • Stores uploaded measurements in a central repository for historical comparison; retention depends on the deployment
  • Create test schedules (FTP, HTTP, voice and more) in a few clicks
  • Browser-based access for authorised users
  • Assign schedules to test devices remotely from the browser
  • Filter and inspect uploaded KPIs by time, location and available measurement criteria
  • Device groups make managing many test devices simple
  • Quick analysis of parameters with charts and graphs
  • Access the management interface through a supported web browser
  • A single central location for controlling and monitoring test devices
  • Pre-analysis helps find problem areas quickly and efficiently
  • Export compatible logs for detailed Sigma-PA analysis
  • Historical performance analysis from uploaded files; customisable layout
  • Drill-down analysis with filters based on time or data range
