Centra-SD

Manage field tests from unified dashboard.

Centra-SD consolidates measurement data into a central repository and shows network performance in a browser interface. Schedule tests on field devices remotely, track their status, and investigate issues on the map as data is uploaded.

Overview

Monitor and manage field tests in one place

Centra-SD serves the whole team through a standard web browser, from anywhere over the internet. Create groups of test devices, build schedules in a few clicks and push them to the field. Devices then collect and upload data to a central repository automatically.

KPIs can be filtered, viewed and drilled down by time, data range and location. Hosting can be Meritech-managed (shared or dedicated) or on a customer server, and the supported deployment size is specified for each project.

Highlights

Why it sits at the centre
of the suite.

Single pane of glass

Connected test devices and their uploaded data sit in one place. Device status is tracked and visible, giving an overview of the whole test network at a glance.

Automatic upload

Scheduled tests start on the devices and their data uploads automatically to the central repository, ready to filter, map and drill into.

Works with Sigma-NEO

Sigma-NEO, a cloud AI application working with Centra-SD, adds automated measurement control, issue detection, root-cause analysis and reports.

Pre-analysis & export

Pre-analysis helps find problem areas quickly. Files for a problem area export to Sigma-PA in one click for detailed analysis, and configured server workflows can produce template reports.

Main features

Three pillars.
One purpose.

Centra-SD brings remote device management, test scheduling, automatic data collection and map-based KPI views into one browser-accessible platform. The tabs below show what it does, what it offers and why it helps.

  • Remotely schedule and monitor test devices
  • Explore KPI data through an interactive map interface
  • Remotely schedules test runs on connected field devices and auto-uploads data to the central repository
  • Works with Sigma-NEO for AI-driven measurement control and analysis
  • Export data for deeper analysis
  • Stores uploaded measurements in a central repository for historical comparison; retention depends on the deployment
  • Create test schedules (FTP, HTTP, voice and more) in a few clicks
  • Browser-based UI — accessible through a standard web browser
  • Assign schedules to test devices remotely from the browser
  • Filter data by many criteria for a bird's-eye view; zoom to 100 m
  • Device groups make managing many test devices simple
  • Quick analysis of parameters with charts and graphs
  • No client software — the whole team accesses from a standard browser
  • A single central location for controlling and monitoring test devices
  • Pre-analysis helps find problem areas quickly and efficiently
  • One-click export to Sigma-PA for detailed analysis
  • Historical performance analysis from uploaded files; customizable layout
  • Drill-down analysis with filters based on time or data range
