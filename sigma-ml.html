Sigma-ML

The drive test. Without
the drive-test rig.

Sigma-ML brings real network measurement to locations where a test vehicle can't go and a test rig is too much kit to carry. A single smartphone, the Sigma-ML app, and a Centra-SD connection is all an engineer needs to capture Layer 1 through Layer 4 data from the device a subscriber actually carries — in real conditions, on any route.

Overview

A tool built for the engineer on foot, not the engineer with a truck.

Traditional drive test requires a vehicle, a rig, trained operators, and significant setup time. Sigma-ML replaces that footprint with a smartphone and an app — capturing the same quality of L1–L4 modem data from the device's chipset directly, in real conditions, as the engineer walks a route or stays in one place.

Measurement data streams to Centra-SD in real time for cloud-based analytics, or stores locally for offline batch processing. The same KPIs, the same decode depth, the same reporting pipeline — with the footprint of a handset in a jacket pocket.

The engineering case

Three pillars.
One smartphone.

Sigma-ML is built on three principles: measurement that runs itself, data that decodes on-site, and voice quality that gets the same rigour as everything else.

01 / Automation
All measurements are automatic.

Every KPI is captured from the moment a walk session starts — no scripting, no configuration sequences, no engineer action required between measurements. The app handles everything. The engineer handles the route.

02 / Decode
Decoded data, no site visits.

Full L1–L4 protocol decode runs on-device and syncs to Centra-SD without the engineer returning to base. Post-processing is cloud-based — the insight arrives before the engineer is back at the office.

03 / Voice
Voice quality, enhanced.

VoLTE voice quality is captured and scored alongside data KPIs using the same measurement session. No separate voice test needed. Coverage gaps in voice are identified the same way coverage gaps in data are.
