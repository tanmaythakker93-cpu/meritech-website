Sigma-AQ

The test that
runs itself

Sigma-AQ is the Android-based drive and walk test tool that collapses a three-person field operation into one. One-click from test to report. Real-time L1–L3 decode on the device in your hand, indoor and outdoor, SSV to competitive benchmarking with one single training.

Overview

A tool built for the engineer driving, not the team back at base.

Sigma-AQ runs on the latest Android smartphones and tablets — Samsung, OnePlus, Xiaomi, Sony — so the device in the test is the same device your customers carry. That's not a shortcut. It's the only honest way to measure what subscribers actually experience.

One-click from test to upload to report. Real-time collection and decoding of Layer 1, 2, and 3 messages. ETSI and ITU-T based QoS/QoE service KPIs. The same tool covers drive test, walk test, SSV, optimization, and competitive benchmarking — with a single training, not three.

Main features

Three pillars.
One purpose.

Sigma-AQ folds measurement, application testing, and indoor coverage into a single Android-based tool — designed to be fast, interoperable, and manageable from the office. The tabs below show what it measures, what it runs, and why it reduces cost.

  • Communicates automatically with attached UEs to collect Layer 1, 2 & 3 data directly from the chipset
  • Live data displayed on maps as the drive happens
  • Saves logged data to disk for further analysis
  • Displays collected data from Layer 1 to Layer 3 in realtime across all panels
  • Real-time L3 decoding with full packet decode
  • Imports and replays saved log data after the session
  • Runs on Samsung Galaxy S25, OnePlus 15, Xiaomi 15, Sony Xperia
  • Multi-RAT: 5G NR, LTE, WCDMA, GSM simultaneous capture
  • GPS + indoor positioning via BLE and Wi-Fi
  • Up to 20 devices in a single coordinated session
  • ETSI TS 102 250 and ITU-T E.804 QoS/QoE KPIs on-device
  • Remote control via Sigma-AQ Boss from the office
  • Same device as subscriber — no measurement gap between test and reality
  • Driver-only van — engineer manages remotely, stays in office
  • One training covers drive, walk, SSV, benchmarking and QoE
  • 50% lower operational cost versus legacy tool approach
  • Report complete before engineer returns from the field
  • No specialist probe hardware — COTS Android devices only
