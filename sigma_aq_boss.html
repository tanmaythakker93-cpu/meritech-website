Sigma-AQ Boss

Coordinated control of
supported test probes.

Sigma-AQ Boss coordinates groups of Sigma-AQ test probes: pair them, distribute scripts, follow progress and failures, and watch live RF and KPI status. Use a local controller for benchmarking and indoor walk tests, or a centralized web service for remote operation, with logs flowing on to upload, processing and reporting.

Overview

One controller for a group of test devices.

Running many probes by hand means repeated manual actions: starting each script, checking each device, collecting each log. Sigma-AQ Boss coordinates the group so engineers supervise execution with fewer repeated steps.

It comes in two arrangements. A local controller suits benchmarking and indoor walk tests. A centralized web service supports remote terminal control, RF/KPI visibility and probe monitoring. Logs then continue to upload, processing and template reporting through the configured server workflow. The supported fleet size is specified for each deployment.
