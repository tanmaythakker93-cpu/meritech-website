Sigma-LA

Multi-device drive testing and protocol visibility

Sigma-LA is a Windows drive test application that captures, monitors and saves RF log data from up to 4 UEs, 2 scan receivers and 1 GPS device at the same time, then replays it after the session. An essential tool for optimising and troubleshooting mobile networks.

Overview

Collect and investigate field measurements

Sigma-LA brings radio conditions, signalling and location into synchronised views for field troubleshooting. It supports multi-device measurements, built-in L1–L3 KPIs and replay of recorded logs. Device connections and campaign settings are configured for the test.

4 UEs
Parallel Capture

Up to four UEs connected at the same time in a single drive session.

2 + 1
Scanners & GPS

Two scan receivers and one GPS device alongside the UEs, all controlled from the same laptop.

L1–L3
Radio and protocol data

Collect chipset measurements with real-time L3 decoding.

Built-in KPIs
Measurement views

Inspect supported radio, throughput and service measurements during the test.

Highlights

Measurement highlights

Multi-device capture

Up to four UEs, two scan receivers and a GPS controlled together, so one drive can cover several networks or technologies.

Real-time L3 decode

L3 messages decoded live and shown as a tree, so you see what the network did without waiting for post-processing.

Synchronised views

Correlate supported protocol messages, measurement graphs and available map data during the test. Configure views for the investigation.

Field-to-replay

Play back field logs with call events on the Cell Search views and the L3 decode synced to the map side by side, with search and speed control.

Configurable measurement

Set up supported devices, test operations and views for the campaign, then collect data using built-in measurement functions.

Built for the operator site

Designed for drive tests at operator sites, with a User Event Marker to flag points of interest and call control for voice and data.

Main features

Monitoring, display and troubleshooting

Configure supported devices and views for field collection, replay and investigation.

  • Communicates automatically with attached UEs to collect Layer 1, 2 & 3 data directly from the chipset
  • Live data displayed on maps as the drive happens
  • Saves logged data to disk for further analysis
  • Displays collected data across all layers in real time on multiple screens
  • Real-time L3 decoding
  • Imports and replays saved log data after the session
  • Windows laptop application; confirm the supported Windows release with Meritech
  • 5G NR, LTE and supported legacy cellular technologies; availability depends on the connected devices, firmware and licence.
  • Up to 4 UEs, 2 scan receivers and 1 GPS connected simultaneously
  • Layer 3 protocol decoding for RRC, NAS and SIB messages
  • Extensive built-in KPIs: throughput, per-radio, and quality metrics
  • Export supported measurements to CSV; replay recorded logs with search and speed control.
  • Built-in KPIs and configurable views support field measurement and troubleshooting.
  • Display imported cell information in Cell Search, with supported scrambling-code selection functions.
  • Pairs natively with Sigma-PA for post-processing and reporting
  • Synchronised displays help make a better judgment of network status
  • Suited to drive tests, optimisation troubleshooting and comparative measurements
  • Laptop based — drive testing in the field with supported UEs, scanners and GPS
