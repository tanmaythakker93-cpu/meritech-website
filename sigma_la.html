Wireless Portfolio / Capture & Automate

Sigma-LA

The quiet instrument
behind better networks.

Sigma-LA is a Windows drive test application that captures, monitors and saves RF log data from up to 4 UEs, 2 scan receivers and 1 GPS device at the same time, then replays it after the session. An essential tool for optimizing and troubleshooting mobile networks.

Overview

A tool built for verification, not demonstration.

Sigma-LA lets an engineer relate a radio condition, a location and a signalling event during troubleshooting, with every measurement source in synchronized views.

It verifies radio network quality through drive tests and supports competitive measurement across networks, with data collection for NR5G, LTE-A, LTE, WCDMA, HSPA, HSPA+, GSM and GPRS. Built-in KPIs, covering Layers 1, 2 and 3, mean an engineer arrives at site ready to capture, not ready to configure.

4 UEs
Parallel Capture

Up to four UEs connected at the same time in a single drive session.

2 + 1
Scanners & GPS

Two scan receivers and one GPS device alongside the UEs, all controlled from the same laptop.

L1–L3
Real-Time Decode

Layer 1, 2 and 3 data from the chipset, with RRC, NAS and SIB messages decoded live as the drive happens.

Full
Built-in KPIs

Throughput, per-radio, and quality KPIs built in out of the box — no scripting required.

Highlights

Why engineers trust Sigma-LA

Multi-device capture

Up to four UEs, two scan receivers and a GPS controlled together, so one drive can cover several networks or technologies.

Real-time L3 decode

L3 messages decoded live and shown as a tree, so you see what the network did without waiting for post-processing.

Synchronized views

Protocol message view, L1 graphs and live maps stay in sync, with handovers and radio link failures shown live. Displays are fully customizable.

Field-to-replay

Play back field logs with call events on the Cell Search charts and the L3 decode synced to the map side by side, with search and speed control.

No scripting to start

Built-in KPIs. Arrive at site ready to capture, not ready to configure. No setup scripts, no template engineering before the first drive.

Built for the operator site

Designed for drive tests at operator sites, with a User Event Marker to flag points of interest and call control for voice and data.

Main features

Three pillars.
One purpose.

Purpose-built for drive test engineers. One workflow that handles monitoring, display, and troubleshooting the way field work actually happens.

  • Communicates automatically with attached UEs to collect Layer 1, 2 & 3 data directly from the chipset
  • Live data displayed on maps as the drive happens
  • Saves logged data to disk for further analysis
  • Displays collected data across all layers in realtime on multiple screens
  • Real-time L3 decoding
  • Imports and replays saved log data after the session
  • Windows laptop application; confirm the supported Windows release with Meritech
  • Supports NR5G, LTE-A, LTE, WCDMA, HSPA, HSPA+, GSM and GPRS
  • Up to 4 UEs, 2 scan receivers and 1 GPS connected simultaneously
  • Layer 3 protocol decoding for RRC, NAS and SIB messages
  • Extensive built-in KPIs: throughput, per-radio, and quality metrics
  • Export to CSV and other standard formats; replay with search and speed control
  • No pre-test scripting — arrive at site ready to capture, not ready to configure
  • Cell Search view reads base-station data from CSV and selects the right scrambling code automatically
  • Pairs natively with Sigma-PA for post-processing and reporting
  • Synchronized displays help make a better judgment of network status
  • Suited to drive tests, optimization troubleshooting and comparative measurements
  • Laptop based — drive testing in the field with supported UEs, scanners and GPS

The post-processing platform that ingests Sigma-LA logs natively. The file that left the field is the file that gets analysed — no conversion.

Smartphone network and service testing for site verification, optimization and benchmarking, alongside Sigma-LA drive tests.

Browser-based management of test devices, with scheduling, automatic upload and performance views by location and time. Data can be exported for deeper analysis.
