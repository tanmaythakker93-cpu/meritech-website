Common Questions

Before you talk
to an engineer.

What is Centra-IoT?
Centra-IoT is a centralized cloud software platform for IoT device management and data visualization. It collects telemetry from sensor devices using standard protocols, processes and stores it in the cloud, and surfaces it through configurable dashboards and management tools — giving teams a single view of every deployed device.
Which protocols does it support?
Centra-IoT supports MQTT and CoAP as primary IoT messaging protocols, as well as Modbus for industrial device connectivity. This means sensors, gateways, PLCs, and connected equipment can connect to the platform without custom adapters or protocol translation layers — if the device speaks a standard IoT protocol, Centra-IoT can receive its data.
Can I integrate my own systems?
Yes. The platform is designed to be customizable — data pipelines, dashboards, and alert rules can all be configured to fit your workflow. For deeper integration with external systems (ERP, SCADA, analytics platforms), the platform exposes APIs that allow processed data to be consumed downstream without manual export steps.
How does Centra-IoT fit with the rest of the IoT stack?
Centra-IoT is the cloud management layer in the monoZ IoT stack. At the edge, devices connect using Xeno+ AI/ML modules for local processing. Connectivity is provided by Mesimo — Meritech's cellular IoT service across 4G LTE, LTE-M, and NB-IoT. Centra-IoT sits above both: receiving, processing, and visualizing everything the fleet sends, turning raw device data into operational intelligence.
