Sigma-One

The test that deploys
where you can't.

Sigma-One captures modem diagnostic data from supported commercial handsets, IoT devices and connected-vehicle units. It supports monitoring-data upload to Centra-SD and detailed log retention within the selected deployment.

Overview

A tool built for the unreachable.

Extend diagnostic measurement to supported devices and remote installations. The device under test must expose a compatible diagnostic interface. Power, connectivity, physical integration, remote tests and the analysis workflow are specified for the deployment.

Main features

What it does.
What it captures.
Where it runs.

Sigma-One supports modem diagnostic capture from compatible handsets, IoT devices and telematics units, with the monitoring and remote configuration specified for each deployment.

  • Capture supported modem diagnostic data
  • Connect devices through the diagnostic interface specified for the hardware configuration
  • Upload supported monitoring data to Centra-SD through the configured connection
  • Collect supported RF measurements and device information
  • Retain detailed logs for retrieval and analysis through the configured workflow
  • Remote SIM management between IoT board and remote handset, as an engineered configuration
  • Power arrangement scoped per installation
  • Engineered configurations for vehicles and remote sites
  • Monitoring data and detailed logs available through the selected deployment
  • Supported modems and chipsets confirmed per device under test
  • Detailed diagnostic files kept for further analysis and reporting
  • Diagnostic capture for supported handset, IoT and telematics device categories
  • Remote SIM switching and power control available as engineered configurations
  • Configure supported devices for stationary, vehicle or remote measurement projects
  • Works with commercial devices that expose a supported diagnostic interface
  • Diagnostic capture across supported device categories
  • Real-device data taken from the chipset through its diagnostic interface
  • Supply monitoring data to a configured Centra-SD deployment
  • Remote management of deployed units; deployment sized to your device count and test volume
USE CASES

Where Sigma-One
earns its place.

Three deployment scenarios where a capture unit beside the device under test is the practical option.

Connected vehicle evaluation

Investigate supported TCU modem behaviour in driving conditions using the vehicle integration agreed for the project.

IoT device evaluation

Capture supported modem diagnostics from IoT modules and connected devices to investigate communication behaviour.

Remote installations

Define the device interface, power, connectivity and retrieval workflow for stationary or remote measurement.
