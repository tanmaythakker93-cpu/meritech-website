Common Questions

Before you talk to
an engineer.

The questions operators and vendors ask us most when they're evaluating the Sigma and Centra family.

Which technologies can the Sigma tools measure?
Sigma-LA supports NR5G, LTE-A, LTE, WCDMA, HSPA, HSPA+, GSM and GPRS. Sigma-ML adds EDGE and collects basic Wi-Fi data such as RSSI and SSID. Both collect L1–L3 data from the device chipset, with real-time L3 decoding. Exact support depends on the device, chipset and licence, so we confirm it against the current compatibility matrix.
How many devices can you drive test simultaneously?
Sigma-LA connects up to 4 UEs, 2 scan receivers and 1 GPS at the same time from one laptop. For larger campaigns, Sigma-AQ Boss coordinates groups of Sigma-AQ smartphone probes, and Centra-SD manages test devices centrally. The supported deployment size is specified for each project.
Do the products work together, or is each one standalone?
Both. Each tool can be used on its own or combined. Sigma-LA and Sigma-ML logs open natively in Sigma-PA for post-processing. Centra-SD schedules tests, collects uploaded logs and offers one-click export to Sigma-PA. Sigma-NEO works with Centra-SD for AI-driven measurement control and analysis. Supported formats are confirmed by file type and version.
Are the tools tied to a specific network vendor?
No. The tools measure from the device side, so the same setup can test different operators and different RAN vendors' equipment. That is what makes competitive benchmarking and multi-vendor acceptance campaigns possible.
Can Meritech run the campaigns, not just supply the tools?
Yes. Meritech wireless services teams deliver the full lifecycle — planning and design, drive and walk test, optimization, RAN tuning, and acceptance — using the same Sigma and Centra instruments, so the people running your campaign are the people who build the tools.
