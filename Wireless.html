Common Questions

Before you talk to
an engineer.

The questions operators and vendors ask us most when they're evaluating the Sigma and Centra family.

Which technologies can Sigma tools measure?
The portfolio supports 5G NR, LTE and legacy cellular technologies in supported configurations. Exact coverage depends on the product, device, chipset, firmware and licence. Contact us for the current compatibility information.
How many devices can you drive test simultaneously?
Sigma-LA connects up to 4 UEs, 2 scan receivers and 1 GPS at the same time from one laptop. For larger campaigns, Sigma-AQ Boss coordinates groups of Sigma-AQ smartphone probes, and Centra-SD manages test devices centrally. The supported deployment size is specified for each project.
How do the products work together?
Select individual products or combine them with the required devices and server services. Sigma-PA supports detailed analysis of compatible logs; Centra-SD supports central operations and measurement consolidation; Sigma-NEO adds AI-assisted workflows. Integration and file compatibility are confirmed for the selected release.
Can the tools compare different networks?
Supported device configurations can measure different operators and RAN environments. A fair comparison requires aligned devices, scripts, routes, service settings and KPI methods.
Can Meritech deliver the campaign?
Meritech provides wireless engineering services as well as testing tools. We can agree a scope covering planning, field measurement, analysis, reporting and optimisation support.
